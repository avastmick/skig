# SKIG usage guides

SKIG connects requirements, architecture decisions, constraints, tasks, code,
tests and evidence so people and agents can follow a system's intent through
to its implementation.

SKIG is free of charge to download and use. Its source code is private.
Linux x86_64 is supported initially; macOS will follow. Windows users need WSL.

1. [Install SKIG](https://github.com/avastmick/skig/wiki/Installation).
2. Choose [Git-based usage](https://github.com/avastmick/skig/wiki/Git-workflow)
   or [a central server](https://github.com/avastmick/skig/wiki/Central-server).
3. Connect your tools using [agent integration](https://github.com/avastmick/skig/wiki/Agent-integration).

See [troubleshooting](https://github.com/avastmick/skig/wiki/Troubleshooting)
when something goes wrong, or check the
[supported standards](https://github.com/avastmick/skig/wiki/Standards).

Downloads are published on [Releases](https://github.com/avastmick/skig/releases).
Use [Issues](https://github.com/avastmick/skig/issues) for bug reports and suggestions.
